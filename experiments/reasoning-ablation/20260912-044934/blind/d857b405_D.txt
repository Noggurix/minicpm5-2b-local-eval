**Minimal example**

```python
import quantumcache
import asyncio
import time

async def main():
    # Use a global shared cache instance
    cache = quantumcache.QuantumCache.shared()   # or QuantumCache.local()
    # Store a value with a 30-second TTL
    key = "my-key"
    value = "cached data"
    await cache.set(key, value, ttl=30)

    # Retrieve the value after a short wait
    start = time.monotonic()
    retrieved = await cache.get(key)
    elapsed = time.monotonic() - start
    print(f"Retrieved: {retrieved} in {elapsed:.2f}s")

    # Wait for TTL to expire
    await asyncio.sleep(35)

    # Attempt to retrieve after expiration; a CacheExpiredError is raised
    try:
        await cache.get(key)
    except quantumcache.QuantumCacheCacheExpiredError as exc:
        print(f"Cache expired as expected: {exc}")

asyncio.run(main())
```

**Explanation of `local()` vs `shared()`**

- `QuantumCache.local()` creates a new `QuantumCache` instance that is bound to the current thread. Each thread that invokes `.local()` gets its own cache instance, effectively isolating caches per thread. This is useful for single‑threaded applications or when you want to avoid sharing state across threads.

- `QuantumCache.shared()` creates a `QuantumCache` instance that is accessible from any thread, i.e., a globally shared cache. All threads receive the same `QuantumCache` instance, and the instance uses thread‑safe mechanisms (e.g., a lock) to protect its internal data structures. This is the typical choice for multi‑threaded, asynchronous environments where you want a single cache that can be used by many threads.

If you need a per‑thread cache for a specific thread but not globally accessible, you would call `QuantumCache.local()` inside the thread. If you need a cache that is shared across threads, you call `QuantumCache.shared()`. For example:

```python
async def thread_local_cache():
    # Each call returns a fresh cache for the current thread
    cache = quantumcache.QuantumCache.local()
    await cache.set("key", "value", ttl=10)
    # ... later await cache.get("key")

async def thread_shared_cache():
    # This cache instance is the same across threads
    cache = quantumcache.QuantumCache.shared()
    await cache.set("key", "value", ttl=10)
    # ... later await cache.get("key")
```

You could also use `global_cache = quantumcache.QuantumCache.shared()` at module level and then access it from any thread.

Now, let's elaborate:

**Why `local()` is different**

`QuantumCache.local()` returns a `QuantumCache` instance that is attached to the current thread. There's no guarantee that the same `QuantumCache` object is reused across calls unless you keep a reference to it. In practice, you might call it as `cache = quantumcache.QuantumCache.local()` in a function and then use that instance.

**Why `shared()` is different**

`QuantumCache.shared()` returns a `QuantumCache` instance that is the same object for all threads, as long as the module is imported. This is a global cache, but the instance itself is thread-safe. The difference is that `shared()` provides a persistent instance that can be accessed from any thread, while `local()` provides per-thread isolation.
