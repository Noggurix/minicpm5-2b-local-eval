### `QuantumCache.local()` versus `QuantumCache.shared()`

- **`QuantumCache()` (the default)** – Creates a cache that is tied to the *local* machine.  
  It shares the same instance across all threads **and** processes running in the same Python process, but each `QuantumCache` instance has its own independent namespace. If you call `QuantumCache.shared()` (if it exists) you’ll get a cache that is shared **globally** across processes, often by using a dedicated‑pooled identifier like `"shared"` in the constructor.  

- **`QuantumCache.shared()`** – In the context of the module (as introduced in Python 3.14) it is a shortcut that creates a *process‑wide* cache. Unlike the default `QuantumCache()` (which is local), `shared()` gives you a cache that lives for the entire process but can be written to be invisible from one process to another (so you don’t see it when other processes run).
